# Contributing

Describe the problem, affected App IDs and the Last result text in an issue first. Keep changes focused and preserve the original zlib notices.

Run `./Build.ps1` on Windows before submitting a pull request. Use synthetic test data; do not require real account writes for regression tests. Availability based on cached permissions must remain distinct from a confirmed save. Respect protected entries and require a reviewed plan before bulk writes.

New interface and documentation text should be in English. Original author attribution remains Rick / gibbed; enhanced edition branding and community credits remain leanz.
